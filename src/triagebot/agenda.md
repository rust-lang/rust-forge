# Meeting agenda generators

The compiler and library teams use an agenda generator to assist with meeting agendas.

## Configuration

This feature has no configuration.

## Implementation

The code for the compiler team agenda resides [here](https://github.com/rust-lang/triagebot/blob/HEAD/src/agenda.rs).

The code for the library team agenda resides [here](https://github.com/rust-lang/libs-team/tree/HEAD/tools/agenda-generator).
